# Focus Urban Interiors — Premium Homepage Concept

A polished homepage concept built from the supplied Focus Urban Interiors brand presentation.

## Stack
- Next.js 15 App Router
- React 19
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```
Open `http://localhost:3000`.

## Production
```bash
npm run build
npm start
```

## Before client launch
Replace placeholder contact details and social links, connect the consultation form/CMS, add verified project copy and photography, and add licensed Code Next font files supplied by the client.
